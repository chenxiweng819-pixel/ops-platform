这个项目用于学习和练习企业常用 Ansible 自动化。
## 内容

- Inventory 主机清单
- 普通 Playbook 写法
- vars_files 变量文件
- NFS 数据共享
- Nginx 安装与配置
- Nginx gzip 和资源优化
- Nginx 反向代理
- Keepalived 高可用
- ansible-galaxy init roles 写法

## 目录结构

```text
inventories/   主机清单
playbook/      普通 playbook 写法
vars/          变量文件
roles/         roles 角色写法
ansible.cfg    Ansible 配置文件
