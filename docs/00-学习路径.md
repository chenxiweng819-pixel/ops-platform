# 学习路径（目标：FastAPI + Ansible 自动化运维平台）

定位：运维熟练工（Ansible/Linux/Docker/K8s/Zabbix 全会）→ 补 Python 后端工程能力。

- [ ] 第 1 周：FastAPI 基础 —— 跑通 main.py，能调 /deploy 和 /health
- [ ] 第 2 周：ansible-runner 接入 —— 把 playbook 变成真 API（见 01-ansible-runner-api.md）
- [ ] 第 3 周：任务化 —— job_id + SQLite 任务记录
- [ ] 第 4 周：平台化 —— JWT 认证 + WebSocket 实时日志 + 部署

## 关键认知
- Ansible 是 CLI 工具，用 ansible-runner 把它变成可编程调用（CLI→Python 参数映射见 01）
- playbook/inventory 放 private_data_dir 的 project/ 和 inventory/ 目录
- ansible-runner 是阻塞子进程，不能放 async 路由里直接 await，要用后台任务/Celery
- 真实主机清单、SSH 密钥永不提交 Gitee
